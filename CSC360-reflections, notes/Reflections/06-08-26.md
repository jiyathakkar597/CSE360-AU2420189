- SSH vs HTTPS: purpose, typical use cases (Git, remote login vs web), and when to choose each
- Computer Graphics vs Image Processing (create vs modify/analyze)
- Geometric primitives: points, lines, curves, polygons/areas, circles/basic shapes
- Java GUI frameworks: AWT, Swing, JavaFX (what each is used for + one key feature)
- Event Listener Model: event source, event, firing, listener + a simple button-click example
- Static vs interactive graphics, and one real example of each
- Connect curves with calculus: differentiation (slope/rate of change) and integration (area)
- Revisit the concept of a digital image as a 2D pixel matrix
- Raster vs Vector: pixels vs math, scaling behavior, resolution/file size implications, examples
- Study Lines & Pixel Graphics:
    - Define pixel (picture element)
    - Explain how a computer chooses pixels to draw a line
- Compare Windows vs Linux:
    - Font rendering differences
    - Driver compatibility differences
- Summarize advantages of Windows over Linux (font rendering, readability for coding, driver support)
