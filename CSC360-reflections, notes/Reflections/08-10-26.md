## Topics covered (revision checklist)

- **Encapsulation and Code Organization:** Discussed the importance of meaningful names, hiding internal implementation details, and separating application code from test code using `src/main` and `src/test`.
- **JavaFX Layouts and Responsiveness:** Reviewed layouts such as `VBox` for vertical arrangement and `StackPane` for layering elements. Discussed how relative sizing helps applications adapt to different window dimensions.
- **JavaFX Application Structure:** Discussed separating UI design using FXML from application logic handled by controllers. Also covered background tasks, splash screens, and the importance of avoiding unnecessary operations during startup.
- **Git Hooks and Commit Messages:** Discussed maintaining clear commit messages and properly acknowledging contributions when using AI coding assistants. A `commit-msg` hook can be used to validate commit messages before they are accepted.
- **Visual Design and Accessibility:** Emphasized reducing unnecessary text, maintaining visual hierarchy, and using one main idea per slide. Also discussed avoiding colour as the only way to communicate information by incorporating labels, shapes, or other visual cues.
- **Project Presentation and Evaluation:** Discussed the importance of demonstrating the working application, explaining the problem and solution clearly, and highlighting important implementation decisions rather than relying on text-heavy slides.
