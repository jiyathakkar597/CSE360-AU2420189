# Lecture — October 22, 2026

## Topics covered (revision checklist)

- **Geometric Distribution:** Discussed the geometric distribution as a model for the number of trials required to obtain the first success. Reviewed its probability mass function, expected value, and variance, along with its distinction from the binomial distribution.

- **Code Documentation and JavaDoc:** Discussed writing meaningful class and method names, keeping comments concise, and using JavaDoc to generate documentation. Explored how JavaDoc tags describe parameters and return values and how generated hyperlinks help readers navigate between classes and methods.

- **Java Project Structure:** Reviewed the organization of production code, test code, and resources. Discussed the importance of following a clear folder structure and using appropriate names for folders containing application resources or demonstration files.

- **Private Constructors:** Discussed restricting object creation when a class is intended to function as a standalone application rather than an externally instantiated object. Emphasized that constructor visibility should reflect the intended design.

- **Testing and Code Quality:** Discussed the importance of writing meaningful tests that verify actual behaviour. Simply creating an object or checking that it is not `null` may not adequately test functionality. Also considered testing application logic separately from graphical interactions.

- **ImageJ and Image Processing:** Introduced ImageJ as both a standalone application and a Java library. Discussed adding it as a project dependency, reading image files, accessing pixel data, and implementing basic image transformations.

- **Pixels and Colour Inversion:** Reviewed RGB pixel values, which range from 0 to 255 per channel in an 8-bit image. Explored colour inversion by subtracting each channel value from 255.

- **ImageJ Plugins and Histograms:** Discussed using plugins to extend ImageJ's functionality and referred to examples in the course repository. The lecture concluded with an introduction to image histograms, which will be explored further in the next class.
