# Lecture — 6 October 2026

## Topics covered (revision checklist)

- Mathematical definitions: well-defined sets, graph representation, directed graphs, and dependence and independence.
- JavaFX event handling: capturing mouse interactions, registering event handlers, and tracing the logic executed in response to user actions.
- Dependency management: specifying library versions and ensuring consistent project behaviour across different development environments.
- Java records: automatically generated constructors and methods, reduced boilerplate, and comparison with regular classes.
- Tree visualization: representing a tree, calculating node positions, drawing edges, and adapting the layout to the available canvas.
- Software design: separating tree structure from layout information, avoiding unnecessary duplication, and assigning clear responsibilities to components.
- Technical presentations: explaining the main problem, demonstrating understanding of the implementation, and presenting technical decisions in a logical sequence.
