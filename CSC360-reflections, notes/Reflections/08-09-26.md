## Topics covered (revision checklist)

* Understand the **event-driven model** in graphical applications
* Revise event sources, event propagation, and event hierarchy
* Understand GUI layout managers
* Differentiate **checkboxes, radio buttons, sliders, and dialog boxes**
* Understand checked and unchecked exceptions
* Revise Java generics and collections
* Prepare for the transition to **digital image processing**

## What we did in class

* Discussed why graphical applications continuously wait for user events
* Explained how an event originates from a source and can propagate through a component hierarchy
* Discussed layout managers and how they handle component positioning during window resizing
* Compared checkboxes and radio buttons based on multiple vs. single selection
* Discussed sliders as an effective way to select continuous values
* Discussed dialog boxes, especially their ability to **maintain context and force user attention**
* Reviewed exceptions, generics, collections, and views
* Introduced preparation for digital image processing and image libraries
