## Topics covered (revision checklist)

* Understand UX considerations when displaying sparse matches in large datasets
* Understand JavaFX **FXML** and splash screens
* Understand modelling files/folders using **tree structures and objects**
* Revise object persistence using **serialization**
* Understand composite progress bars and **multithreading**
* Understand **graceful thread cancellation**

## What we did in class

* Discussed how to display a small number of matches from a large list without unnecessary scrolling
* Discussed using indices and ellipsis/break notation to communicate gaps between results
* Discussed the purpose of splash screens and the information they can display
* Introduced FXML for defining JavaFX interfaces
* Discussed representing a file system as a tree of objects with editable properties
* Discussed saving object state to disk using serialization
* Discussed running multiple jobs using threads and displaying their individual progress
* Introduced graceful cancellation, where threads receive a signal and safely complete their cleanup before stopping
