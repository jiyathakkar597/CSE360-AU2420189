## Topics covered (revision checklist)

* Understand how the number of equations and variables affects whether a system has a unique solution
* Revise matrices, vectors, and their relationship to systems of equations
* Understand how circles can be represented using their centre and radius
* Understand **stacks (LIFO)** and **queues (FIFO)** and their real-world uses
* Understand Java Swing **events and listeners**
* Understand mouse clicks, dragging, coordinates, and event handling
* Learn how the distance formula can be used for geometric collision/containment checks
* Understand how to break a graphics project into smaller implementation tasks

## What we did in class

* Discussed why fewer equations than variables generally result in multiple possible solutions rather than a unique solution
* Discussed representing systems of equations using matrices and column vectors
* Discussed implementing a circle-and-arrow canvas using Java Swing
* Explored how mouse listeners can detect clicks and provide the mouse coordinates
* Discussed using mouse dragging to create directed arrows between circles
* Discussed checking whether a point lies inside a circle using the distance from the centre and the radius
* Derived/revised the distance formula using the Pythagorean theorem
* Discussed using a **stack** to implement undo functionality by removing the most recently created circle
* Compared stacks and queues using the LIFO and FIFO concepts
* Discussed the difference between graphical drawing and representing structures using console characters
* Discussed the design and implementation requirements for a graphical project involving circles, directed arrows, mouse interaction, and undo functionality.
