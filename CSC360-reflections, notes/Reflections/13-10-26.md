# Lecture — 13 October 2026

## Topics covered (revision checklist)

- Model–View–Controller (MVC) architecture: the roles of the model, view, and controller, including the controller's function as an intermediary.
- Java GUI threading: the main thread, Swing's Event Dispatch Thread (EDT), and the effect of long-running tasks on UI responsiveness.
- Background execution: the purpose of executor services and separating computational work from GUI event handling.
- Progress monitoring: individual task progress, overall progress, concurrent jobs, and independent task cancellation.
- GUI framework selection: evaluating Swing and JavaFX based on project requirements, compatibility, and maintenance trade-offs.
- Java properties: the importance of understanding unfamiliar classes and APIs through documentation and experimentation.
- Project presentations: writing clear problem statements, defining meaningful objectives, explaining design decisions, and demonstrating technical understanding.
