# Maven and JavaFX Setup

## Maven

**Maven** is a build automation and dependency management tool commonly used in Java projects. It helps manage external libraries and simplifies the process of building and running applications.

Instead of downloading `.jar` files manually and setting up their paths, Maven can manage these dependencies through the project's configuration. Libraries such as **JavaFX** can be added and maintained this way.

## JavaFX Shape Rendering: Fill and Stroke

JavaFX provides properties that control the appearance and placement of 2D shapes such as a `Rectangle`.

- **Fill:** `setFill(...)` sets the color or appearance of the inside of a shape.
- **Stroke:** `setStroke(...)` defines the color of the shape's outline.
- **Transparent Fill:** Using `Color.TRANSPARENT` for the fill makes the inside transparent while keeping the outline visible.
- **Stroke Width:** `setStrokeWidth(...)` controls the thickness of the outline.
- **Position:** `setLayoutX(...)` and `setLayoutY(...)` can be used to position the shape within its parent.
- **Dimensions:** `setWidth(...)` and `setHeight(...)` specify the width and height of a `Rectangle`.

### Example

A rectangle can be displayed as a filled shape by assigning a color to its fill. To display only its boundary, the fill can be made transparent and a stroke color can be specified.
