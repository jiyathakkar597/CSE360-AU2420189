##  Drawing a Centered Square

### Coordinate Units and Canvas Parameters

* **Basic measurement:** In 2D computer graphics, positions and dimensions are commonly represented using **pixels**.
* **Canvas dimensions:** To place a square correctly, we need the canvas width `W`, canvas height `H`, and the square's side length `L`.
* **Canvas center:** The midpoint of the canvas can be calculated using:

  ```text
  cx = W / 2
  cy = H / 2
  ```

  This point becomes the center of the square.

---

### Finding the Four Corners

In a typical screen coordinate system, `(0, 0)` is at the **top-left corner**. The X-coordinate increases toward the right, while the Y-coordinate increases downward.

If the square has its center at `(cx, cy)` and its side length is `L`, half of the side length is `L / 2`. Therefore, the corners can be calculated by moving half the side length from the center.

* **Top-left:** `(cx - L/2, cy - L/2)`
* **Top-right:** `(cx + L/2, cy - L/2)`
* **Bottom-left:** `(cx - L/2, cy + L/2)`
* **Bottom-right:** `(cx + L/2, cy + L/2)`

The **top-left coordinate** can then be used as the starting point for drawing the square.

---

### Pseudocode

```text
FUNCTION drawCenteredSquare(canvasWidth, canvasHeight, sideLength):

    // Find the center of the canvas
    centerX = canvasWidth / 2
    centerY = canvasHeight / 2

    // Find the top-left corner of the square
    startX = centerX - (sideLength / 2)
    startY = centerY - (sideLength / 2)

    // Draw the square
    drawRectangle(
        x = startX,
        y = startY,
        width = sideLength,
        height = sideLength
    )

END FUNCTION
```

---

### Key Idea

The main idea is to calculate the square's position from the **center of the canvas**. Subtracting half of the square's side length from the center gives the top-left starting point.

This approach keeps the square centered even if the canvas dimensions change.
