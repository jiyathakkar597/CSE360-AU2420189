# Java Swing, Anonymous Classes, and Graphics Math

## Java Swing: JFrame, JPanel, and Graphics

- **Basic structure:** create a `JFrame`, insert a custom `JPanel` (or component) into it, and call `setVisible(true)`.

- **Custom shapes:** to draw custom shapes, extend `JPanel` and override the `paintComponent(Graphics g)` method.

- **The Graphics object:** the `Graphics` object is passed automatically to `paintComponent` — you do not retrieve it manually.

- **Parent setup:** always call `super.paintComponent(g)` first when overriding, to let the parent class handle its own setup (clearing background, drawing borders, etc.).

- **Color state:** `setColor()` acts like choosing a pen — all subsequent draw calls use that color until changed.

- **Drawing rectangles:** `drawRect(x, y, width, height)` takes a top-left point plus width and height as its four parameters.

  ```
  drawRect(x, y, width, height)
  ```

## Anonymous Classes in Java

- **Definition:** an anonymous class is a subclass defined inline without a name, used when the subclass is only needed once.

- **Syntax:** simultaneously defines a subclass and creates an instance:

  ```java
  new ParentClass() {
      @Override
      // method overrides here
  };
  ```

- **Related concepts:** nested classes, static nested classes, and inner classes are briefly related but distinct concepts.

## Math in Computer Graphics: Triangles and Lines

- **From lines to vertices:** drawing a triangle from three line equations (not three points) requires finding pairwise intersection points by solving systems of equations.

- **Triangle inequality:** any two sides must be greater than the third side.

  ```
  a + b > c
  b + c > a
  a + c > b
  ```

- **Boundary method:** to generate valid triangle sides, pick `A` and `B` arbitrarily, then choose `C` within the range:

  ```
  |A - B| < C < A + B
  ```
