## Generic programming

**Generic programming** means writing reusable code that can work with different types of objects. 
Instead of writing separate code the same generic logic can be reused.

**Basic idea:**

`Write once → Reuse for different types`

This reduces repeated code and makes applications easier to extend.

## JavaFX Shape objects

JavaFX provides a general **Shape** abstraction for graphical objects.

Examples include:

- Lines
- Circles
- Rectangles
- Other geometric shapes

Instead of treating every shape completely differently, common operations can be handled through the `Shape` abstraction.

## Graphics Context

A **Graphics Context** is used to perform drawing operations.

The general idea is:

`Shape → Graphics Context → Draw`

This allows graphical objects to be handled using a more general drawing mechanism.

## Shape properties

Graphical objects can have different properties that affect their appearance.

For example, a line can have a specific **thickness**.

So drawing involves both:

- **Geometry** — what and where the object is
- **Properties** — how the object appears

## Mutable vs. immutable

An object is **mutable** if its state or properties can be changed after it is created.

An object is **immutable** if its state cannot be changed after it is created.

**Simple idea:**

`Mutable → can change`

`Immutable → cannot change`

This distinction is important when working with objects because changing an existing object and creating a new object can have different effects on a program.
