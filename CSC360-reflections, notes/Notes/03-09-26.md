## 1. UX for Large Lists

* When a large list has only a few matches, display **only the matching items** instead of making the user scroll through thousands of entries.
* Show the **original indices/positions** so the user knows where the matches occurred.
* Large gaps can be represented using:

  * Ellipsis (`...`)
  * Break/zigzag notation
* This is a **User Experience (UX)** consideration: the display should communicate gaps without overwhelming the user.

## 2. JavaFX Splash Screen

* A **splash screen** appears while a desktop application is loading.
* It improves UX by showing that the application has started and is still loading.
* It can display:

  * Application name
  * Version
  * Basic environment/build information
* **FXML** is an XML-based format used to define JavaFX UI elements such as buttons, panels, and their properties.

## 3. Object Modelling & Tree Structure

* An **object** is a program representation of something from the real world or system.
* Files and folders can be represented as objects.
* A file system naturally forms a **tree structure**:

  * Folder → parent
  * Files/subfolders → children
* A UI can display this structure using a tree panel and an editor panel for object properties.

## 4. Saving Objects

* Changes made to objects must be saved to **disk** so they remain consistent after restarting the application.
* Java provides **serialization** to save objects and restore them later.

## 5. Composite Progress & Threads

* A **composite progress bar** represents the progress of multiple jobs.
* Multiple jobs can run concurrently using **threads**.
* Jobs should be independently controllable, including cancellation.

### Graceful Cancellation

* A thread should generally not be forcefully terminated.
* Instead, the program sends a **cancellation signal**.
* The thread checks the signal and finishes/cleans up safely before stopping.
* This prevents problems such as unfinished operations or resources/files being left open.

### Key Takeaway

Good software combines **UX, appropriate data structures, persistence, concurrency, and safe resource management**, not just basic functionality.
