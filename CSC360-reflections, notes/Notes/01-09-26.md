# Geometric Objects & Event Handling

## 1. Systems of Equations

* A system with fewer equations than variables generally has **multiple solutions**, not a unique solution.
* For `n` variables, `n` independent equations can give a unique solution.
* Systems of equations can be represented using **matrices and vectors**.

---

## 2. Circle Representation

A circle can be represented by:

* Centre: `(x, y)`
* Radius: `r`

To check whether a point `(x, y)` lies inside a circle with centre `(xc, yc)`:

$$
\sqrt{(x-x_c)^2+(y-y_c)^2} \leq r
$$

---

## 3. Mouse Events in Java Swing

A graphical application responds to events such as:

* Mouse clicks
* Mouse dragging
* Mouse release

A **listener** is registered with a component such as `JPanel` to handle these events.

For the graphics project:

```text
Mouse Event → Listener → Get Coordinates → Perform Action
```

---

## 4. Drawing Circles and Arrows

* A right-click can be used to create a circle at the mouse position.
* Store the circle's **centre and radius** for later use.
* Dragging from one circle to another can create a **directed arrow**.
* The release point can be checked to determine which circle was selected.

---

## 5. Stack for Undo

A **Stack** follows **LIFO (Last In, First Out)**.

It is suitable for undo operations:

```text
Create Circle 1
Create Circle 2
Create Circle 3
       ↓
Undo → Circle 3 removed
```

A **Queue** follows **FIFO (First In, First Out)** and is useful when items must be processed in arrival order.

### Key Takeaways

* Use mathematical conditions to handle geometric objects.
* Use **event listeners** for user interaction.
* Use the **distance formula** for point-circle detection.
* Use a **stack** for undo functionality.
* Break a graphics problem into smaller components before coding.
